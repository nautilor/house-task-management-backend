# House Task Management Backend

Backend of a personal project that i use to manage various things in my house.

It is based off the [Token Economy](https://en.wikipedia.org/wiki/Token_economy) concept.

I run this project on a Raspberry Pi 4 with a PostgreSQL database on my local network so there is not authentication.

## Technologies

- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
- [PostgreSQL](https://www.postgresql.org/)
- [TypeORM](https://typeorm.io/)
- [Docker](https://www.docker.com/)
- [AJV](https://ajv.js.org/)
- [reflect-metadata](https://www.npmjs.com/package/reflect-metadata)


## Features

- Manage tasks like cleaning,etc... divided by categories
- Manage the freezer content
- Manage Vegetables with recipes for them
